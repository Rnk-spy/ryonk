# RYONK — Intelligence Meets Creativity

**RYONK** is a web-based AI assistant project designed to bring intelligence and creativity together in one place.

🌐 **Live Website:** https://rnk-spy.github.io/ryonk/  
📦 **Repository:** https://github.com/Rnk-spy/ryonk

## ✨ Overview

RYONK is a lightweight web application with an AI assistant interface and configurable AI integration.

The project is designed with a simple and accessible web-based experience.

## 🚀 Features

- Modern AI assistant interface
- Configurable AI provider settings
- Interactive user interface
- Lightweight HTML, CSS, and JavaScript architecture
- GitHub Pages deployment support

## 🛠️ Technologies

- HTML5 — Website structure
- CSS3 — Styling and layout
- JavaScript — Application logic
- GitHub Pages — Website hosting

## ⚙️ Installation

1. Clone this repository:

```bash
git clone https://github.com/Rnk-spy/ryonk.git
```

2. Open the project folder.
3. Open `index.html` in your browser.

## 🌍 Deployment

This project uses GitHub Pages.

To deploy:

1. Open repository Settings.
2. Navigate to Pages.
3. Select **Deploy from a branch**.
4. Choose branch `main`.
5. Select folder `/(root)`.
6. Save your settings.

Your website will be available at:

https://rnk-spy.github.io/ryonk/

## 🔧 AI Configuration

RYONK includes a configurable AI setup.

AI functionality requires a valid provider configuration. Without it, the application may operate in DEMO mode.

**Note:** Never publish private API keys or credentials in a public repository.
